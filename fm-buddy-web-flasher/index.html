FM Buddy 2.0

Install from the browser onto a PCBfun / Freenove ESP32-S3 2.8" board.

This browser can’t flash. Web Serial works in Chrome or Edge on a computer — not Safari, not Firefox, not a phone or tablet. Open this page in one of those, or flash from a terminal with esptool.

Update — keeps your settings

Writes the app and tells the board to boot it. Your Wi-Fi, theme, MIDI setup and touch calibration are untouched, because the settings partition is never written. This is the one to use.

Full install — erases everything

Writes the whole flash from zero: bootloader, partition table and app. Your settings are erased. Only for a board that will not boot, or a brand new one.

If the board doesn’t appear

  1. Use a USB-C cable that carries data. A charge-only cable is the usual reason.
  2. On the board: Settings › Flash mode › Restart for flashing.
  3. Or hold BOOT, tap RESET, let go of BOOT.
  4. Close anything else using the port — a serial monitor, the Arduino IDE, PlatformIO.

Before you click: there is no backup here

A browser cannot read your board’s flash back, so this page cannot take a copy first the way the desktop scripts do. The update path never writes the settings partition, so your settings are safe by construction — but if you want to be able to return to the exact firmware you are running now, take a backup from a terminal first:

  • ./pcbfun_backup_mac.sh in the source package, or
  • esptool.py --chip esp32s3 read-flash 0x10000 0x640000 app0-backup.bin

Older releases are on the repository’s Releases page, so any published version can be put back from here.
